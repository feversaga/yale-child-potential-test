# 耶鲁大学儿童潜能测试 · 微信小程序版

把 [耶鲁大学儿童潜能测试 Skill](../) 做成了**微信小程序**，家长在手机上就能给孩子做天赋测评，无需打开电脑。

基于耶鲁大学罗伯特·斯滕伯格（Robert Sternberg）教授的儿童潜力评估理论，通过 20 道行为观察题，发现孩子藏在日常里的天赋方向。

---

## ✨ 功能

- 🌟 **完整模式** — 20 道题逐题 1-5 分点选，结果最精准
- ⚡ **快速模式** — 直接从 20 个表现里勾选最像的 3 项，秒出结果
- 📊 **6 大天赋维度报告** — 语言表达 / 逻辑思维 / 音乐节奏 / 视觉空间 / 人际洞察 / 运动身体，自动排名并给出职业方向与培养建议
- ☁️ **云端历史记录**（可选）— 用微信云开发保存每次评测，可回看多个孩子/多次结果

---

## 🚀 本地运行（最快）

1. 下载本仓库，进入 `wechat-miniprogram/` 目录
2. 用**微信开发者工具**打开该目录（导入项目）
3. AppID 先用「测试号」即可直接预览（此时历史记录功能会自动隐藏）
4. 手机扫码或模拟器即可体验完整测评流程

---

## ☁️ 开启云端历史记录

1. 在微信开发者工具中，把项目 AppID 换成你自己的**小程序 AppID**（测试号不支持云开发）
2. 顶部点击「云开发」，开通后在控制台看到你的**环境 ID**
3. 打开 `app.js`，把 `cloudEnvId` 填上你的环境 ID：

   ```js
   cloudEnvId: '你的云开发环境ID'
   ```

4. 在云开发控制台创建数据库集合 **`assessments`**，权限设为「所有用户可读，仅创建者可读写」
5. 重新编译，测评完成后结果会自动存入云端，历史页可回看

> 不填 `cloudEnvId` 也能正常使用测评与报告，只是不保存历史。

## 📁 目录结构

```
wechat-miniprogram/
├── app.js / app.json / app.wxss      # 全局配置与云开发初始化
├── project.config.json               # 项目配置（改 AppID 用）
├── data/questions.js                 # 20 道题 + 6 维度 + 职业/培养建议
├── utils/score.js                    # 计分与报告生成逻辑
└── pages/
    ├── index/   首页（模式选择 + 孩子信息）
    ├── quiz/    完整模式（逐题打分）
    ├── quick/   快速模式（勾选 3 项）
    ├── result/  结果报告（含云端保存）
    └── history/ 历史记录（云开发）
```

题库、维度映射、计分逻辑与 Skill 完全一致。
