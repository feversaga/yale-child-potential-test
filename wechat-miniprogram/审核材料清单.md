## 二、用户隐私保护指引（必填）

### 1. 勾选的收集项（后台勾选框）

- ☑ **收集你储存的信息** — 用于本地生成测评报告及云端保存历史记录
- ☑ **收集你的微信 OpenID** —（仅在开启「云端历史」时使用）用于标识用户身份以回看历史测评记录

> 说明：若不开通云开发历史功能，可只勾选第一项，OpenID 项不勾。

### 2. 收集信息的目的、方式、范围（粘贴到后台文本框）

```
本小程序是一款儿童潜能测评工具，基于家长对孩子的日常行为观察进行天赋评估。

一、我们收集的信息
1. 家长主动填写的孩子称呼、年龄、性别；

二、收集目的与方式

若用户主动开启「云端历史」功能，相关数据将通过微信官方云开发（CloudBase）安全存储，
用于回看历史测评记录；该存储与本小程序账号绑定，仅本人可见。

三、信息共享与保护
我们不会将上述任何信息用于测评以外的用途，不会与任何第三方共享或出售。
所有数据均通过微信官方云开发环境加密存储，家长可随时在「历史记录」页面删除单条或全部记录。
```

## 三、上传 / 审核步骤

1. 微信开发者工具导入 `wechat-miniprogram/` 目录
2. 把 `project.config.json` 里的 `appid` 改为你小程序的真实 AppID
3. （可选）把 `app.js` 里的 `cloudEnvId` 填为你的云开发环境 ID（不填也能测评，只是不保存历史）
4. 点「上传」→ 填版本号 `1.0.0`、备注「儿童潜能测试Pro」
5. 公众平台 → 版本管理 → 开发版本 → 提交审核
6. 在审核信息页**底部「用户隐私保护指引设置」选「采集用户隐私」**，粘贴第二部分文案（入口②）
7. 审核类目填「工具 > 信息查询」，功能页面填 `pages/index/index`
8. 审核通过 → 发布
