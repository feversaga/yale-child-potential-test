## 🌟 为什么你需要这个测试？

**每个孩子都是独一无二的**——

你有没有发现孩子某些行为特别突出：有的孩子走路带风、律动感超强；有的小嘴叭叭不停、纠错比你还快；有的问"时间从什么时候开始"这种问题把你问懵……

但这些日常行为背后，**到底藏着什么天赋？未来往哪个方向培养？**

这个测试不需要孩子答题，你只需要回忆日常，20道题一答，就能得到一份**天赋维度排名 + 职业方向建议 + 日常培养指南**。

## 🎯 六大天赋维度

| | 天赋维度 | 行为观察点 | 潜力方向 |
|:---:|:---|:---|:---|
| 🗣️ | **语言表达与文字** | 背诗敏感、爱纠错、会讲故事 | 作家/编辑/律师/翻译/主持人 |
| 🧮 | **逻辑思维与数理** | 爱问抽象问题、记路标、爱分类 | 科学家/程序员/分析师/工程师 |
| 🎵 | **音乐与节奏** | 韵律感强、编剧情、辨声敏感 | 音乐家/作曲/音响工程师 |
| 🎨 | **视觉与空间想象** | 方向感好、爱乐器、情动关联 | 建筑师/设计师/摄影师/导演 |
| 🤝 | **人际交往与洞察** | 察言观色、好奇自然、点评声音 | 心理咨询/外交/市场/教师 |
| 🏃 | **运动与身体感知** | 协调性好、画地图、准确评价他人 | 运动员/舞蹈/外科医生/机械师 |

## 🚀 如何使用

### WorkBuddy 用户（推荐）

这是一个 **WorkBuddy Skill**，一句话就能跑：

```
测测孩子的天赋
```

或者直接说：
```
耶鲁大学孩子潜力测试  / 孩子天赋测试  / 宝宝潜力自测
```

> 需要 [WorkBuddy](https://www.codebuddy.cn) 客户端，导入 Skill 即可使用。

### 两种测试模式

| 模式 | 说明 | 耗时 |
|:---|:---|---:|
| 🌟 **完整模式** | 20道题逐题1-5分打分，精确评估 | 约5分钟 |
| ⚡ **快速模式** | 从20个表现里挑3个最像的，秒出结果 | 约1分钟 |

### 每题按5分制打分

```
1 🟢 完全不符合
2 🔵 偶尔有，不常见
3 🟡 有时会，不算明显
4 🟠 比较符合，经常这样
5 🔴 非常符合，说的就是他
```

所有选项带标注，**直接点选**，不用打字。

## 🧑‍🔬 学术背景

> **罗伯特·斯滕伯格（Robert J. Sternberg）**
> 
> 耶鲁大学心理学教授，美国心理学会（APA）前主席，智力三元论提出者。

> 强调每个人的天赋是多维度的，不能用单一标准衡量。
